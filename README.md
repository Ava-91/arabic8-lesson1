# عربی ۸ — درس اول

ابزار تعاملی آموزش و مرور **درس اول عربی هشتم: «مُراجَعَةُ دُروسِ الصَّفِّ السّابِعِ»**.

## امکانات
- مرور اولیه ۱۰ سؤالی
- آموزش موضوعی
- تمرین تعاملی با بازخورد فوری
- آزمون نهایی ۲۰ سؤالی
- ذخیره پیشرفت در مرورگر
- مرور اشتباهات

## فناوری
HTML5 · CSS3 · Vanilla JavaScript · localStorage · GitHub Pages

بدون backend، database یا حساب کاربری.

## ساختار
- `index.html` — پوسته برنامه
- `css/styles.css` — طراحی واکنش‌گرا
- `js/data.js` — داده‌های آموزشی و بانک سؤال
- `js/storage.js` — ذخیره پیشرفت
- `js/app.js` — رابط کاربری، routing و موتور آزمون
- `.github/workflows/pages.yml` — انتشار GitHub Pages

## منبع
مبنای محتوایی: کتاب «عربی، زبان قرآن ۲» پایه هشتم، چاپ ۱۴۰۵، درس اول. محتوای تعاملی باید پیش از تحویل نهایی با نسخه کتاب و تدریس مدرسه تطبیق داده شود.
